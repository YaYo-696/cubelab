# Changelog

## 1.0.0

- Timer con mezclas filtradas para 2×2, 3×3 y 3×3 a ciegas, inspección por modalidad, sesiones y estadísticas.
- Academia bilingüe con lecciones, catálogos verificados, evaluación y recomendaciones.
- Solucionador por etapas para 2×2 y 3×3 con un worker cancelable y un visor 3D.
- Entrenador cronometrado y de reconocimiento con repaso espaciado y estadísticas por caso.
- Introducción en la primera apertura, preferencias de apariencia, control de avisos y borrado local con respaldo.
- PWA instalable con preparación diferida del contenido sin conexión y publicación de preview y release en GitHub Pages.
- Respaldo JSON v3 con importación de las versiones 1 y 2.
